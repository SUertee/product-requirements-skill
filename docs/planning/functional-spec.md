# 功能开发 Spec v0.1

2026-11-17，根据 [开发流程](development.md)、[模块职责](../architecture/modules.md) 和当前源码制定。本文定义目标行为与验收条件，实际实现与测试证据维护在 [工程进度](../progress/implementation.md)。

## 目标与使用者

PM／FDE 从客户会议、录音或逐字稿创建项目，结合前情形成带原话依据的需求。内部团队评审方案和 PRD，确认后生成可交互原型，最终按选定版本向客户分享。后续反馈回到原需求并保留变更。

主链路为素材接收 → 转写与来源标准化 → 需求分析与建模 → 文档／工作台 → 定义确认 → 原型／图示 → 最终复核 → 客户发布包。

首个验收样例使用合成客户项目，覆盖首次会议和第二次反馈。真实妙记、ASR 服务、华为宿主和公网部署分别记录外部验证结果。多人在线编辑继续暂缓，录屏先处理音轨，画面理解作为后续能力。

## 功能与验收

| 编号 | 功能 | 正常行为 | 异常／恢复 | 验收条件 |
| --- | --- | --- | --- | --- |
| F01 | 素材与前情 | 本地文件／指定妙记接收，保留原件、项目、来源、时间定位，逐字稿可关联录音，前情可关联现有项目 | 坏字幕、无音轨、资源无权、产物未就绪分别记录，同输入去重、重试留历史 | 原件内容一致，来源可定位，重复提交保持身份，跨项目关系被拒绝 |
| F02 | 分析任务 | 从来源、前情与基线生成宿主分析请求，接收结构化分析结果，校验后生成新版本 | 待宿主、执行中、失败、完成可查，坏结果保留错误及已有产物，重复完成可识别 | sources → project → PRD／工作台贯通，错误引用无法发布，正常返回不覆盖人工锁定字段 |
| F03 | 需求与模型 | 八要素、稳定 REQ、模块、规则、异常、验收、实体、字段、关系、页面任务关联同一基线 | 未知保留疑问，推断／建议标记，需求取消保留历史 | 需求可回查原话，第二轮可对照新增／修改／取消，已有 ID 与锁定字段受保护 |
| F04 | 文档与工作台 | 按模板生成方案和 PRD，七页展示真实来源、任务、模型、版本及成果 | 部分生成失败保留已完成文档，缺失内容显示实际状态 | 文件入口可用、引用与校验和一致、导入数据按文本安全展示 |
| F05 | 定义评审与修订 | 保存意见，按版本导出与应用，形成新项目版本及变更记录 | 旧 revision、错误版本、重复应用、锁定冲突有可查结果 | 旧版本不变，决定有来源与影响对象，核心范围／规则／验收确认后允许生成对应原型 |
| F06 | 交互原型 | 基于已确认页面规格及内置 UI 生成可交互主流程，页面关联 REQ，示例数据明确 | 未确认定义、缺页面行为或字段时返回具体问题，生成错误可修订 | 至少完成核心任务、校验、结果与返回路径，真实接口／模拟能力明确 |
| F07 | 图示与 ERD | 适配 Archify 和 Schema Canvas，生成与登记同版本 HTML，汇入技术设计 | 依赖缺失、输入不完整、生成检查失败各自记录 | 实际调用可追溯，实体／字段与输入一致，逻辑关系与真实外键明确 |
| F08 | 反馈与客户交付 | 最终复核绑定版本，按文件选择生成可部署客户包，后续反馈形成下一轮分析输入 | 无复核、版本不匹配、内部文件误选、路径越界被识别，发布失败保留包 | 客户包资源自包含，包含选定原型与发布记录，内部会议、PRD 和凭据保持其受众范围 |
| F09 | 后台接入 | 目录接收和妙记就绪触发进入统一任务，ASR 通过已配置的本地命令或宿主协议接入 | 文件未稳定等待，重复事件去重，依赖／权限失败可恢复，进程重启后保留任务 | 可重复运行接收／处理，阶段和失败位置可见，模型及转写目的地以运行配置为准 |
| F10 | 宿主与真实样本 | 在选定会议和码道／果办中演练相同链路，按授权验证部署入口 | 缺少宿主、真实样本或凭据时保留具体信息缺口与已完成证据 | 保存环境、输入、操作、实际结果与限制，用户完成验收确认 |

## 页面行为

| 页面 | 本轮开发行为 | 测试重点 |
| --- | --- | --- |
| 总览 | 显示当前版本、任务状态、成果和变更摘要，进入对应任务或评审 | 任务与成果状态独立，旧版结果不冒充当前版本 |
| 会议素材 | 文件／妙记导入、前情关联、转写状态、原话与媒体定位、发起分析 | 超限、坏输入、无权、重复、未就绪、时间定位和失败重试 |
| 功能需求 | 模块／状态／证据筛选、原话回查、需求修订与锁定、变更预览 | 空结果、跨模块关联、来源稳定、锁定冲突 |
| 方案文档 | 对应版本单篇阅读、文件下载、定义评审入口 | 章节、长内容、未知字段和版本一致性 |
| 原型预览 | 生成任务、页面切换、设备预览、实际交互、关联需求 | 主流程、必填校验、异常、返回和模拟标识 |
| 技术设计 | 图示生成状态、流程架构／数据库／API、来源与版本 | 缺依赖、字段一致、关系、嵌入、键盘标签 |
| 评审记录 | 定义／发布两个阶段、意见保存与应用、差异、客户包选择 | revision 冲突、版本匹配、重复应用、内部资料范围 |

页面视觉与内容规范沿用 [工作台规范](../../product-requirements/references/ui-design.md)，实现资源继续维护在包内 assets。

## 执行与数据协议

- 素材继续使用 job.json 和 sources.jsonl。输入内容作为分析数据，动作由用户请求与宿主任务控制。
- 分析请求包含 request_id、project_id、目标版本、基线版本、来源与前情清单、输入摘要、输出约束。宿主返回 project.json，执行器以现有 read_inputs 校验项目和来源。
- 分析执行状态使用 waiting_host、running、failed、completed，保留 attempt、error、输入摘要和结果目录。接收完成与语义分析完成分别记录。
- 评审导出绑定 project_id、artifact_version 和 review_stage。应用决定、项目字段修订和版本差异作为显式输入，输出新的目录，保留旧值、新值、依据和冲突。
- 外部产物登记 path、generator、生成器版本、输入版本、source_ids、受众、检查结果及校验和。文件来自明确的产物根目录，工作台按实际清单构建入口。
- 定义确认与发布确认绑定具体项目版本及确认范围。原型生成使用已确认范围，客户发布包使用最终复核记录和显式文件选择。
- 同一材料和处理版本去重。并发完成、输出占用和中断重试需保留一致的基线与产物清单。

## 开发顺序

1. 固化 F01 基线，扩展安全附件类型、来源元数据和回归样例。
2. 完成 F02 的分析请求、结果接收、运行状态和版本发布，将接收箱连接到现有生成器。
3. 完成 F03／F05 的差异、锁定保护、评审应用与定义确认，补齐 API 和工作台操作。
4. 完成 F07 的外部产物适配、检查与登记，生成真实流程图及 ERD 并嵌入工作台。
5. 完成 F06 的页面规格、原型生成和任务演练，覆盖确认范围与模拟行为。
6. 完成 F08 的发布复核、客户包和反馈导入。
7. 完成 F09 的目录稳定检测、去重、ASR／宿主命令协议和恢复，核对事件接入条件。
8. 执行 F10 真实样本、浏览器和比赛宿主联调，按实际结果记录验收。

开发在 dev/workbench-foundation 的功能分支实施。每一步先完成数据与失败路径，再接页面，最后跑回归和样例链路。

## 测试方案

### 自动回归

- 保留现有文本、字幕、材料路径、Connector、HTTP、review revision 和文档生成测试。
- 增加分析任务的并发提交、重复完成、非法引用、其他项目结果、旧基线、输出占用及失败恢复。
- 增加评审应用的旧版本、重复决定、取消需求、锁定冲突、差异、原型确认与发布文件范围测试。
- 外部生成器使用契约桩验证异常路径，并对可用的真实固定依赖执行至少一份合成模型。
- DOM 测试覆盖七页、任务状态、原话双向跳转、生成／评审操作、错误反馈与版本切换。

### 端到端演练

使用含明确需求、未知预算、冲突规则和第二次反馈的合成会议。依次完成导入、宿主分析、生成 v1、人工确认、图示／ERD／原型、发布包、反馈形成 v2。保存来源、请求、项目、review、diff、manifest、生成器结果与验收记录。

### 人工和外部验证

#### 比赛宿主选择

2026-11-17 核对华为云官方活动指南，当前明确列出码道 IDE 和码道 CodeArts 网页端作为 Skill 创作与市场上传入口。项目优先以码道 IDE 联调本地文件、Python 脚本和 HTML 工作台，实际安装、加载和自动任务调用分别验收。[官方活动指南](https://support.huaweicloud.com/offers-codeartsagent/codeartsagent_offers_0008.html)

官方 IDE 规范要求技能目录与 SKILL.md 的 name 一致，支持项目级 `.codeartsdoer/skills/` 和本地 ZIP 导入。当前包名统一为 `product-requirements`。IDE 导入 ZIP 限制为 5 MB，比赛提交限制需在提交时另行核对。宿主实测记录安装版本、依赖路径、输入及真实输出，客户原型部署目标独立记录。[官方技能规范](https://support.huaweicloud.com/usermanual-codeartsagent/codeartsagent_ug_0024.html)

#### 验证项目

- 桌面与窄屏核对导航、中文长文本、键盘、焦点、局部滚动、音视频定位、主流程和浏览器报错。
- 真实妙记确认读取权限、文件格式、说话人及时间戳，比较逐字稿与原录制。
- ASR 核对真实转写差错、时间对齐、模型、耗时和费用，缺少项保持未知。
- 华为宿主核对加载方式、任务调用、依赖位置与输出。公网部署按用户选定账号／目标执行，记录实际 URL。

## 验收与交接

F01—F09 逐项保存实现、自动测试、样例证据与剩余限制。完成条件为对应表格中的可观察行为真实成立，文件与代码可以复现。

F10 的浏览器、真实会议、ASR 和华为宿主分别给出结果，实际缺失的外部条件继续列出。自动测试通过、待验证与用户验收分别记录。交接提供 spec、运行命令、工作台入口、测试记录、源码提交及未完成事项。
