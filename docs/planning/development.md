# 模块开发顺序

模块职责与输入输出见 [模块拆分](../architecture/modules.md)，字段见 [数据契约](../architecture/contracts.md)，实际完成与验证见 [工程进度](../progress/implementation.md)。

| 阶段 | 开发范围 | 交接与验收 |
| --- | --- | --- |
| 输入基础 | M01 文本／字幕标准化与来源定位 | 稳定片段 ID、段落或时间定位，重复输入结果一致 |
| 需求与模型 | M02 事实理解、八要素、REQ 卡；M03 业务模型 | 原话引用有效、未知与冲突可见，字段与关系有依据 |
| 文档定义 | M04 方案书与 PRD | 正常与异常行为可评审，范围和规则经人工确认 |
| 成果生成 | M05 原型、M06 图示／ERD、M07 工作台 | 主流程可操作、成果版本一致、入口有效 |
| 增量修订 | M08 差异、锁定、双阶段复核与发布 | 旧值新值可查、人工修改保留、客户版本可核对 |
| 语音与自动接入 | M01 ASR、PC 后台与录音设备接入 | 记录实际质量、费用、传输能力与失败恢复 |
| 宿主与交付 | 比赛宿主、依赖、运行包与部署 | 核对真实运行结果、许可、包体积及文件数量 |

开发使用 dev/workbench-foundation 及其功能分支。接口变更同步核对生产者与消费者，验证记录注明输入、源码版本、环境、结果和限制。
