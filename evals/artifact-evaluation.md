# Artifact 评估

## 内容而非存在性

- proposal 和 PRD 引用真实 REQ，包含角色、流程、功能、非功能、规则、异常、集成、风险与验收。
- PRD 与原型读取同一 Baseline 的验收标准，不各自改写规则。
- 工作台能浏览项目、历史、Evidence、REQ、模型、PRD、版本和待确认。
- 原型只含已确认 REQ，主流程可操作，包含空态、错误态和返回路径。
- 示例数据、模拟接口和固定样例审批清晰可见，无真实接口或发布伪造。
- manifest 只登记真实文件，版本、REQ 关联和校验结果准确。

## 浏览器验证

真实 Agent 运行时使用可用浏览器工具打开 HTML，执行主流程、空态、错误态和返回，记录实际结果；没有浏览器工具时只能声明静态检查通过，不能声称交互已验证。
